# CHARTERPULSE AI --- User Workflows

## New Procurement

``` text
Cargo -> Quantity -> Origin -> Destination -> Delivery Window -> Contract Preference -> Run Analysis
```

## Analysis

``` text
Requirement -> Candidate Ports -> Candidate Vessels -> Freight Forecast -> Feasibility -> Cost -> Risk -> Recommendation
```

## Global Port Intelligence

Search by country, region/city, port or UN/LOCODE. Filter by cargo
capability, vessel compatibility and operational status. Inspect
constraints, congestion and freshness where available.

The map is an operational tool, not decorative imagery.

## Recommendation

Show action, selected strategy, expected delivered cost, uncertainty,
feasible vessel/port, reasons, risk, freshness and alternatives.

## Human decision

`Approve`, `Modify`, `Reject`, with reason and timestamp.

## Outcome

Capture actual freight, delay, demurrage, delivered cost, arrival and
notes.

## Dashboard principle

Prioritize decisions and exceptions over decorative charts. Every major
metric should answer what is happening, why, what to do, how certain it
is and how fresh the data is.
