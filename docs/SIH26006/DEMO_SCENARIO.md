# CHARTERPULSE AI --- SIH26006 Demo Scenario

## Objective

Show how CHARTERPULSE changes a procurement decision from reactive
market checking to forecast-driven, constraint-aware decision support.

## Flow

1.  Create bulk cargo requirement.
2.  Enter quantity, origin, destination and delivery window.
3.  Discover candidate ports.
4.  Check vessel compatibility using capacity, draft, LOA, beam and
    terminal constraints.
5.  Show historical freight and P10/P50/P90 forecast.
6.  Optimize feasible strategies.
7.  Run freight/fuel/congestion/weather what-if scenarios.
8.  Show recommendation: `BOOK_NOW`, `WAIT`, `CHANGE_PORT`,
    `CHANGE_VESSEL` or `REVIEW`.
9.  Human approves/modifies/rejects.
10. Later record actual freight, delay, demurrage and delivered cost.
11. Compare forecast/recommendation with actual outcome.

## Integrity

Exact demo values must be labelled as real sourced data or
`SIMULATED — DEMO DATA`.

Never present fabricated live market data or unsupported
confidence/savings.

## Judge takeaway

CHARTERPULSE does not merely predict freight. It connects forecasts with
physical port/vessel feasibility, cost optimization, risk and human
procurement decisions.
